# 兔子动画打包说明

本文记录 `jingling` 兔子外观如何从 PNG 和 Spriter SCML 源文件，编译为饥荒联机版可加载的 `anim/jingling.zip`。

## 前置条件

- 已通过 Steam 安装 **Don't Starve Mod Tools**。
- 游戏与 Mod Tools 位于同一个 Steam 库盘符。当前机器路径为：
  - 游戏：`D:\software\steam\steamapps\common\Don't Starve Together`
  - 工具：`D:\software\steam\steamapps\common\Don't Starve Mod Tools\mod_tools`
- 已安装的本地 Mod：
  `D:\software\steam\steamapps\common\Don't Starve Together\mods\dont-starve-ai-mod`

## 项目内源文件

兔子动画源文件位于：

```text
game-mod/
  anim_source/jingling/
    jingling.scml
    jingling_front.png
    jingling_left.png
    jingling_right.png
    jingling_back.png
```

- `jingling.scml`：Spriter 动画描述，定义 `idle`、`walk_loop` 等动画。
- PNG：每个动画帧使用的图片。图片需要带透明通道。

## 为什么不能只把 PNG 放进 Mod

DST 实体动画不能直接加载 PNG。PNG 必须由 Klei 官方 Mod Tools 编译，得到含 `anim.bin`、`build.bin` 与纹理数据的 ZIP。最终 ZIP 需要放在 Mod 的 `anim/` 目录，并在 `modmain.lua` 中注册：

```lua
Assets = {
    Asset("ANIM", "anim/jingling.zip"),
}
```

## 编译步骤

`autocompiler.exe` 会扫描**已安装 Mod 根目录**下的 `exported/`，而不是工作区目录。因此先复制完整的 SCML 项目到该目录。

在 PowerShell 中执行：

```powershell
$source = "F:\Project\mod\dont-starve-ai-mod\game-mod\anim_source\jingling"
$modRoot = "D:\software\steam\steamapps\common\Don't Starve Together\mods\dont-starve-ai-mod"
$export = Join-Path $modRoot "exported\jingling"

New-Item -ItemType Directory -Force -Path $export
Copy-Item -LiteralPath "$source\jingling.scml" -Destination $export -Force
Copy-Item -LiteralPath "$source\jingling_front.png" -Destination $export -Force
Copy-Item -LiteralPath "$source\jingling_left.png" -Destination $export -Force
Copy-Item -LiteralPath "$source\jingling_right.png" -Destination $export -Force
Copy-Item -LiteralPath "$source\jingling_back.png" -Destination $export -Force

& "D:\software\steam\steamapps\common\Don't Starve Mod Tools\mod_tools\autocompiler.exe"
```

成功时会显示 `Exporting Animation` 和 `Atlasing`，最终文件为：

```text
D:\software\steam\steamapps\common\Don't Starve Together\mods\dont-starve-ai-mod\anim\jingling.zip
```

## 回写到项目

为使项目保留可发布的成品，将生成的 ZIP 回写到工作区：

```powershell
Copy-Item `
  -LiteralPath "D:\software\steam\steamapps\common\Don't Starve Together\mods\dont-starve-ai-mod\anim\jingling.zip" `
  -Destination "F:\Project\mod\dont-starve-ai-mod\game-mod\anim\jingling.zip" `
  -Force
```

然后同步 `game-mod\anim\jingling.zip` 与 `game-mod\modmain.lua` 到实际 Mod 目录，重启世界测试。

## 修改动画后

每次修改任一 PNG 或 `jingling.scml` 后，重复“编译步骤”和“回写到项目”。不要手动解压或修改最终 ZIP；应始终以 PNG/SCML 为源文件重新编译。
